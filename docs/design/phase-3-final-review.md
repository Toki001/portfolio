Motion timing and cleanup: entry masks 500ms mobile / 720ms desktop with capped row delays; body 360/460ms; rules 360/480ms in rows, 350ms in labels; gallery 180ms; native zoom/menu 220ms; filter reflow 280ms. Rare editorial entrances intentionally exceed frequent-control budgets. Progress-rule scale starts at zero because it represents a drawn line, not a popover/content surface. All changing scroll/motion properties are transform/opacity. No layout animation, recurring timer, duplicate library, per-frame React state or general wheel handler was added. Pointer layers are separate from entrance/scene owners. Keyboard/live reduction/hidden-page handlers settle pending work; no-JS is static.

Verdict is scoped to source review, the actual Chromium captures, executed route/gesture/keyboard/axe tests and local lab profiles. Physical devices, Safari/Firefox and screen-reader speech were unavailable. Final measurements and acceptance are recorded in milestone-20.md after the final performance pass.

Performance review: the first M20 index sample was 94 with CLS 0.062. Reserving native filter geometry removed that shift; prioritizing the primary phone over the decorative secondary lifted the index to 95. Art-directed derivatives remove already-hidden screenshot pixels, with separate hashes/crops and unchanged full gallery media. Final matched measurements: home mobile 97 / desktop 100 / PesoFlow mobile 99 / index mobile 95; Accessibility/Best Practices/SEO 100 throughout; CLS 0 throughout. Home/index simulated LCP is 2.56/2.85s, above the baseline's 2.20/2.40s and the index's near-2.5s aspiration. This is disclosed as the remaining performance tradeoff of the expanded presentation; no field-vitals or universal speedup claim. Original reports and intermediate diagnostics are retained. Final JS gzip adds 5.87kB, within the 10kB budget.

**Approve**, scoped to this Chromium/source review: no remaining feel-breaking motion finding in the reviewed changes, no artificial waits on controls, bounded finite entrances, interruptible gallery/filter/toggle feedback, keyboard/reduced-motion/static fallbacks and separate pointer transform owners. Actual final frames were decoded and inspected for the portrait, featured artwork, new cases and capability/tool rows. The desktop recorder's post-control scroll position was corrected at the evidence level by opening each genuine screen in native zoom; no product layout was changed to manufacture a capture. Remaining lab LCP tradeoff and unavailable physical/browser-engine checks are explicitly reported above, not treated as verified passes.
